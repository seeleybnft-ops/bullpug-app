## Restore commands

### Frontend
```bash
cd /app/frontend/src && tar -xzf /app/memory/archive/bot_frontend_2026-05-12.tar.gz
```

### Backend
```bash
cd /app/backend && tar -xzf /app/memory/archive/bot_backend_2026-05-12.tar.gz
# Then in routers/__init__.py:
#   - Add: from routers.ai_trader import router as ai_trader_router
#   - Add: from routers.signal_analytics import router as signal_analytics_router
#   - Add both to ALL_ROUTERS list
# And in utils/scheduler.py: re-add auto_trade_scan_cycle() + check_auto_trade_exits()
#   from scheduler_extracts/dead_bot_functions.py
sudo supervisorctl restart backend
```

### MongoDB collections
```bash
python3 /app/memory/archive/restore_bot_collections.py
```
The script skips any collection that already has docs (won't overwrite live data).
